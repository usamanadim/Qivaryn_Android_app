# Qivaryn 0.1.1

Maintenance release that fixes the audio track of downloaded Reels and makes
the app report why a download failed.

This is a **pre-1.0 beta**. The app currently targets a single platform, so the
version stays on the `0.x` line; `1.0.0` is reserved for the feature-complete
release that works across every planned platform.

## Highlights

- **Reels keep their sound.** Instagram serves Reel video as DASH streams that
  are often VP9 or AV1. Android's own MP4 writer only stores H.264 and H.265, so
  the audio track could not be muxed into the video and the Reel was saved
  silent. Media3 does the muxing now, so the 1080p stream keeps its audio. If a
  device cannot copy a codec, the engine falls back to Instagram's progressive
  stream, which already carries the final audio — a download can no longer end
  up without sound.
- **Failures say what went wrong.** A failed download now shows the actual
  reason (an expired Instagram session, a private post, rate limiting, a
  network problem) instead of a generic message, and tapping the row opens the
  details with a shortcut to the cookie manager.
- **A real cookie check.** "Check Cookie Status" contacts Instagram and reports
  whether the imported session is still valid, rather than only checking that a
  file exists.
- **Smaller app.** The bundled FFmpeg copies are gone: Android does not allow
  executing binaries from app storage, so they could never run. The APK is now
  37 MB instead of 84 MB.
- **Cookie imports are tidier.** Only `instagram.com` cookies are kept from an
  export, so a full browser export no longer copies unrelated sessions into
  the app.

## Updating

This build follows the beta channel: it offers newer `0.x` pre-releases and
`1.0.0`+ stable releases. Installing an update preserves cookies, download
history, settings, and `Downloads/Qivaryn`.

## Notes

- Beta software: expect rough edges; report issues on the repository.
- Reels already downloaded without audio are not re-processed. Delete the file
  and use **Settings → Clear download records** to download it again.
