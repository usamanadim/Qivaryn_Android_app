# Qivaryn 0.1.0

First public build of the Qivaryn Android app, published from its own repository
([`usamanadim/Qivaryn_Android_app`](https://github.com/usamanadim/Qivaryn_Android_app))
instead of the Python engine repository.

This is a **pre-1.0 beta**. The app currently targets a single platform, so the
version stays on the `0.x` line; `1.0.0` is reserved for the feature-complete
release that works across every planned platform.

## Highlights

- On-device Instagram media downloader: Kotlin + Jetpack Compose UI with the
  Qivaryn Python engine compiled into the APK.
- Single posts/reels, **All Reels**, and **All Posts** bulk modes.
- Downloads land in the public `Downloads/Qivaryn` folder through MediaStore on
  Android 10+, with history, thumbnails, opening, and sharing.
- Persisted dark mode using the centralized `QivarynColors` palette.
- **Software update** now checks this repository on the **beta** channel, so
  future beta and stable releases install directly from the app.

## Updating

This build follows the beta channel: it offers newer `0.x` pre-releases and
`1.0.0`+ stable releases. Installing an update preserves cookies, download
history, settings, and `Downloads/Qivaryn`.

> Coming from an older internal development build numbered `1.0`? That build
> compares as newer than `0.1.0`, so it will not be offered this release
> automatically. Install `0.1.0` once manually; after that, in-app updates work
> normally.

## Notes

- Beta software: expect rough edges; report issues on the repository.
- The bundled FFmpeg binary used for video/audio merging is arm64 only. Other
  ABIs download video without audio merging rather than crashing.

## Assets

- `Qivaryn-0.1.0-universal.apk` — signed release APK
- `checksums.txt` and `Qivaryn-0.1.0-universal.apk.sha256` — SHA-256 checksums,
